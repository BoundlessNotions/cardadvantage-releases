# CardAdvantage releases

Desktop builds of CardAdvantage, a collection manager and deck builder for Magic: The Gathering players. Download the latest build from [Releases](https://github.com/BoundlessNotions/cardadvantage-releases/releases/latest).

Install instructions, the privacy policy, and support are on the website: https://cardadvantage.boundlessnotions.com

The Android app is on Google Play. This repository holds build artifacts only; it has no source code and does not take issues.
